# Finite Occupied--Virtual Orbital Parameterization

Date: 2026-08-05
Status: mathematical idea retained from deleted legacy reference code

## Retained Idea

Let a one-particle reference coordinate system place `n_o` occupied
coordinates first and `n_v` virtual coordinates afterward. For a real
occupied--virtual amplitude matrix `K` of size `n_v x n_o`, define

```text
L = K'K

       [ cos(sqrt(L))                   ]
C(K) = [ K sin(sqrt(L)) / sqrt(L)       ].
```

The quotient is the analytic matrix function `sinc(sqrt(L))`, continued to
one at zero. This is the occupied part of the finite orthogonal rotation
generated by the block-skew matrix

```text
[  0  -K' ]
[  K    0  ],
```

and therefore gives orthonormal occupied columns for finite `K`, rather than
using only a linearized orbital response. It is a useful chart for
conventional full-space orbital optimization when the reference occupied and
virtual spaces are explicitly available.

The deleted implementation also encoded an analytic chain rule for this map.
For a spectral decomposition `L = U diag(lambda) U'` and a scalar matrix
function `f`, its Fréchet derivative can be written

```text
Df_L[E] = U ((U' E U) .* f_divided_difference(lambda)) U',
```

where the off-diagonal entries are

```text
(f(lambda_i)-f(lambda_j))/(lambda_i-lambda_j)
```

and coincident diagonal entries use `f'(lambda_i)`. Applying this separately
to `cos(sqrt(L))` and `sin(sqrt(L))/sqrt(L)`, followed by the chain rule for
`L=K'K`, gives an analytic energy gradient with respect to `K`.

## Required Caveats

- The chart assumes the special occupied-first reference coordinates above.
  It is not a formula for arbitrary physical-basis orbitals without first
  constructing and tracking the reference occupied/virtual frame.
- The historical zero-angle formulas and near-degenerate divided differences
  were not numerically hardened. Stable implementations need series expansions
  or tested matrix-function/Fréchet-derivative routines around zero and clustered
  eigenvalues.
- This is conventional full-space orbital optimization. It is not HFDMRG
  history acceleration, which builds a contracted model from several sweep
  determinants, and it is not forbidden-determinant hill searching.
- The deleted file's Fock builders, damping, DIIS, block transforms, and
  `Optim`/`FastEigs` integration are obsolete and are not part of this retained
  idea.

Any revival should be a fresh, bounded implementation using stable matrix
functions, finite-difference and projector-based gradient tests, and HFDMRG's
current backend Fock routines. It should first demonstrate a concrete advantage
over the maintained SCF and history-acceleration paths.
