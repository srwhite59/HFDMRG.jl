# HFDMRG.jl v0.1.0 release notes

These notes describe the first public release. The repository visibility,
`v0.1.0` tag, and GitHub release are applied only after the final release
commit passes hosted CI.

## Highlights

- Compact typed unit-cell RHF and independent-spin UHF solvers use one moving
  block collection and return compact state/result records without global
  occupied-coefficient panels.
- A streamed producer-energy observer evaluates a caller-supplied,
  uncompressed density-density Hamiltonian without mutating the compact state.
- Historical dense, sliced, cached, target-residual, frozen-occupied, and
  history routes remain available behind distinct matrix/backend dispatch and
  retain their global `(psiup, psidn, energy)` result contract.
- Checksummed physical H10/H20 inputs provide self-contained compact RHF/UHF
  examples without PPP, GaussletBases, private checkpoints, or path callbacks.
- Julia 1.12 compatibility, isolated checked-bounds tests, strict Documenter
  checks, and an MIT license are included.

## Reproducibility and evidence boundary

The distributable physical reproduction boundary is the H10/H20 fixture in
`examples/data/hydrogen_chains_v1`. Its four recorded RHF/UHF outcomes were
generated from a clean HFDMRG checkout using only distributed data and declared
dependencies.

The checked-in H2/H10/H20/H100/H1000 validation records establish recipient
extraction equivalence, compact ownership, and bounded performance. The frozen
PPP commit `0bcd4f11831a98ae4bf4fb3d09eac5968df9d96c` is the algorithm donor and
benchmark oracle for the extraction records. Paper headline calculations and
their timings belong to the separately recorded PPP/paper-calculator workflow;
they were not generated by the public HFDMRG package release and must not be
reported as recipient timings.

Compact `represented_energy` is the energy of the working interaction.
`producer_energy` is a separate observational evaluation and does not certify
producer-Hamiltonian stationarity or a global Hartree--Fock minimum.

## Installation and first runs

HFDMRG.jl v0.1.0 requires Julia 1.12. After the repository and `v0.1.0` tag
are public, the library can be installed directly from its Git URL:

```sh
julia -e 'using Pkg; Pkg.add(url="https://github.com/srwhite59/HFDMRG.jl", rev="v0.1.0")'
```

That command installs the package into the active Julia environment; it does
not copy repository examples into the caller's working directory. To run the
shipped examples after the repository and tag are public, clone the tagged
source and activate that checkout:

```sh
git clone --branch v0.1.0 --depth 1 https://github.com/srwhite59/HFDMRG.jl.git
cd HFDMRG.jl
julia --project=. -e 'using Pkg; Pkg.instantiate()'
```

Recommended first runs from that checkout are:

```sh
julia --project=. examples/quickstart.jl
julia --project=. examples/basic_uhf.jl
julia --project=. examples/compact_uhf.jl
julia --project=. examples/compact_producer_energy.jl
julia --project=. examples/physical_hydrogen_chain.jl h10 rhf
julia --project=. examples/physical_hydrogen_chain.jl h10 uhf
```

The README and manual explain the compact versus historical dispatch and result
contracts. The full H10/H20 commands and evidence boundary are in
`docs/src/manual/reproducibility.md`.

## Known boundaries

- H100/H1000 paper-scale construction inputs and machine-local checkpoints are
  not distributed; their compact records are evidence, not standalone public
  reproductions.
- The private/provisional history drivers are retained for chemistry workflows
  but are not a public acceleration interface.
- Hosted documentation, a Julia registry entry, archival DOI integration, and
  paper preferred-citation metadata are not part of v0.1.0.
