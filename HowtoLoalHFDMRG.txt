How to load HFDMRG (default environment)

Same machine (one-time setup):
1) Develop the local repo into the default Julia environment:
   ~/codexhome/cjulia -e 'using Pkg; Pkg.activate(); Pkg.develop(path="/Users/srwhite/codexhome/work/hfdmrg")'
2) Use it from anywhere (default env):
   ~/codexhome/cjulia -e 'using HFDMRG; println("HFDMRG loaded")'

Another machine (copy then develop):
1) Copy or clone the repo to a local path, e.g. /path/to/hfdmrg
2) Develop that path into the default Julia environment:
   julia -e 'using Pkg; Pkg.activate(); Pkg.develop(path="/path/to/hfdmrg")'
3) Use it from anywhere (default env):
   julia -e 'using HFDMRG; println("HFDMRG loaded")'

Notes:
- If you activate another project with --project or Pkg.activate("/some/project"),
  you will need to develop HFDMRG into that project as well.
- To remove HFDMRG from the default environment:
  julia -e 'using Pkg; Pkg.rm("HFDMRG")'
